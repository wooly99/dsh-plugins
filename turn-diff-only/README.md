# 仅显示本轮代码差异

轻量 UI 插件，无依赖、无构建脚本，不改 DSH 源码，不操作 DOM。

## 1.1.0 修正

旧版错误地禁用了整个 Agent 预设 UI，连标准模式、创造模式都隐藏了。新版**保留整个内置预设模块及其控制器**，只对两个界面的显示过滤条件做局部处理：

- **保留**新任务的标准模式、创造模式选择器，以及设置中的对应预设卡片、Creator 入口和自定义预设。
- **隐藏**内置 PTC、Minimal 扩展模式的选项；已选模式的标签仍按原生界面显示。
- **隐藏**轨迹视图。
- **保留**原生每轮差异卡片、预览、交付文件卡片和原生打开动作，不复制或替换这些功能。
- 不更改会话预设、默认预设或 Host 预设定义；不卸载其他插件。

## 实现与开关

补丁只屏蔽 `ui-trajectory`。前端通过公开的 Slots `entries` / `subscribe` / `register` 接口，对原生 `conversation.hero.agentPreset` 和 `settings.section` 的 `agent-presets` 单元格做可撤销覆盖：保留原组件、注入数据、操作回调、翻译和排序，只把用于视图过滤的 `developerTools` observable 固定为 `false`。因此仍使用 DSH 自己的“基础模式”过滤规则，自定义预设保留。

原生差异卡片仍依赖通用设置中的“显示代码工作视图”总开关，前端激活时会通过官方 configForms 接口开启它（与 1.0.2 相同）。**总开关仍会开启，但不会让 PTC/Minimal 选项出现，也不会隐藏标准/创造模式。** 这个开关保留 DSH 原有语义，例如 HTML 预览权限；插件没有另外提升 Host 权限。初始化失败会记录错误，可手动在通用设置开启。

不会克隆拥有子 Slot 声明的交付文件组件，不修改其他插件的注册对象，也不拦截预设选择 API。原组件重注册或卸载时，覆盖随之更新或撤销。

## 恢复

在插件管理中停用或卸载**整个组合包**，即可撤销轨迹屏蔽和模式过滤。只关闭组合包内部的 Host 插件行不会撤销 YAML 补丁。总开关不会自动关闭，若需要可手动关闭。

改动对当前 profile 的所有会话生效；中键关闭、归档清理、Codex 接入等其他插件保留。

## 本地安装和验证

用 DSH 的插件管理器安装本目录。目录采用本地链接安装时，不要删除源码目录。若管理器要求重启，以其返回提示为准。

```sh
node --check index.js
node --check client.js
node --test tests/*.test.mjs
```

测试覆盖只屏蔽轨迹、基础模式过滤保留原组件和回调、原注册不被修改、注册生命周期/卸载恢复、总开关写入与并发保护。图标为原创 SVG。
