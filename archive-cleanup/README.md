# 归档清理

在 **设置 → 通用** 里多出一行「归档清理」：显示已归档会话数量和占用空间，点「清理」并确认后，永久删除这些会话并释放磁盘。

- 只处理**已归档**的会话；未归档的会话不会被动到。
- 删除内容：会话日志目录、子代理会话、投影缓存、提醒与工作区记录。独立分叉的会话不受影响。
- 正在使用、正在运行或仍有活动的会话会**跳过**，并在结果里提示跳过了几个。
- 归档操作仍用 DSH 自带的「归档」，插件只负责清理，不自动删除。

仅支持当前 DSH 的 JSONL 存储。**永久删除不可恢复**，清理前可在 DSH 里先取消归档要保留的会话。

测试：`node --test archive-cleanup/tests/purge.test.mjs`（仓库根目录执行，只操作临时数据）。
