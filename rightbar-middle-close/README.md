# Right Sidebar Tab Middle-Click Close

在右侧边栏（「文件 / 开始」那一栏）的某个标签上点击鼠标中键，关闭**这个标签页**，和浏览器标签页的中键关闭一致。

## 行为

- 只关闭被点中的那个标签；中键点在标签的任意位置都算（标签文字、内边距、标签上的关闭 ×、标签图标）。
- 收起规则沿用侧栏自己的规则，因为内部调用的是和标签 × 完全相同的关闭路径：
  - 会执行标签类型注册的关闭处理（例如终端、文档预览的清理/确认）；
  - 唯一一个「开始」引导标签不能被关闭，中键它不会发生任何事；
  - 关掉最后一个标签时，右侧边栏随之收起（等价于点 × 的收栏行为）。
- 栏内标签以外的区域（文件树、预览正文、工具菜单、面板空白处、右上角的面板按钮）中键不关闭标签，也不会收起侧栏。
- 停靠栏和浮动面板共用同一套 `role="tab"` 标签控件，因此两边都适用；若某个浮动面板的标题不是 tab 控件，则不在范围内。
- 命中标签时吞掉这次中键事件：不会触发浏览器「中键新标签打开链接」，也不会启动 Chromium 的中键自动滚动；其它位置的中键保持浏览器原生行为。

## 实现

- 浏览器半部（`client.js`）在 `document` 捕获阶段监听 `mousedown`（抑制中键自动滚动）与 `auxclick`（完成的中键点击）。
- 命中判定：目标向上找到右侧边栏内的标签条控件 `[role="tab"]`，并从该控件（或其内部 `data-sidebar-right-tab` 标记）读出标签 id。标签**正文**也带 `data-sidebar-right-tab`，但不在 `[role="tab"]` 内，因此正文里的中键不会被误判。
- 关闭动作只调用一次 `ctx.sidebarRight.close(tabId)`；这正是侧栏标签 × 控件使用的 `controller.closeIn` 路径，所以关闭处理、唯一引导标签保护、关最后一个标签即收栏等行为都不需要插件重复实现。
- 插件声明 `inject: ['sidebarRight']`，右栏插件不存在时不激活；不注册任何 Slot，不写 DOM。
- Host 半部（`index.js`）是空 `apply()`：让 profile 携带 bundle，并为插件页提供标题、描述与图标。

## 限制

- 未做真实页面验证：本次会话没有浏览器控制能力，只验证了 JavaScript 语法、清单、安装结果与右栏控制器 `close`/`isExpanded` 等公开方法。实际手势需要在已打开的 GUI 中刷新页面后确认。
- 依赖 Chromium/现代浏览器的 `auxclick`（Chrome 55+、Firefox 53+、Safari 15+）。
- 标签条控件识别依赖右栏发布的 `role="tab"` 语义；若将来侧栏把标签条换成非 ARIA tab 控件，需要同步调整判定选择器。
