# 界面小增强 · UI Enhancements

将零散的界面便利功能放在一个插件里。目前包含 **3 个独立组件**：

| 组件 | 行为 |
|---|---|
| 侧栏标签中键关闭 | 中键点击右侧边栏标签，按原生 × 的逻辑关闭该标签。 |
| 会话工作区标记 | 顶部会话标题的模式标签后，显示文件夹图标和当前会话所属工作区名称；悬停查看完整路径。 |
| 折叠工作区状态 | 工作区折叠时，在标题行最右侧显示运行转圈、待处理黄点或未查看完成蓝点。 |

显示名称由「侧栏标签中键关闭」改为「界面小增强」，**包标识仍为 `@local/dsh-rightbar-middle-close`，目录仍为 `rightbar-middle-close`**，避免老用户装出两个重复插件。它是一个组合包，不是三个需要分别安装的插件。

## 组件 1：侧栏标签中键关闭

- 只关闭被点中的标签：文字、内边距、关闭 ×、标签图标均可命中。
- 调用 `sidebarRight.close(tabId)`，与原生 × 共用标签关闭处理、唯一「开始」标签保护、最后一个标签关闭后的收栏行为。
- 文件树、预览正文、菜单、面板空白处的中键不受影响。
- 停靠栏和浮动面板只要使用原生 ARIA tab 标签条就适用。
- 命中标签时抑制中键自动滚动及新标签打开行为，其他位置保持原生行为。

## 组件 2：会话工作区标记

- 使用原生 `conversation.session.header.actions` 列表槽，位于模式标签之后；不替换顶部栏、不查询或改写宿主 DOM。
- 以该槽的 `sessionId` 查找工作区成员关系，优先显示工作区自定义名称，路径使用工作区根目录 `path`。
- 没有工作区关联的会话，回退到该会话的 `cwd`，显示末级目录名；没有目录信息时不显示。不会误用其他会话的全局选择或本进程的工作目录。
- 自动默认工作区名称显示为「默认工作区」/「Default workspace」。
- 切换会话、修改工作区名称/关联或更新目录时，原生 selector Hook 自动订阅并重新渲染，无轮询、额外 HTTP 请求或手工读取会话文件。
- Windows、UNC 和 POSIX 路径均可显示；长名称省略，悬停提示保留完整路径。使用宿主主题文字颜色。
- 纯展示，不切换工作区、不修改会话设置。原生顶部栏在空白新会话隐藏时，标记也不显示。

## 组件 3：折叠工作区状态

- 仅在真实工作区折叠时显示，展开后隐藏汇总标记，由原生会话行展示详情；「未分组」桶不处理。
- 主图标优先级：**运行转圈 → 等待审批/计划确认/回答的黄点 → 有未查看完成结果的蓝点 → 空闲无标记**。
- 运行态使用原生 UI 状态，缺失时回退到会话摘要，并计入原生子代理目录中的运行项。没有给所有历史会话建立 retention，也不订阅发送中的乐观回显，因此发送到运行信号到达之间可能有短暂空档。
- 完成提示直接使用原生 `completionUnread`，不是聊天消息未读、最后消息时间或成功校验。取消/失败结束也可能形成此提醒；它随查看对应会话或重新运行而由 DSH 清除。插件不另行持久化提醒，也不会因展开工作区就将会话标记为已读。
- 多个会话并存时只显示一个主图标，悬停提示保留运行、等待与未查看完成的数量。转圈优先时，未查看结果不会丢失。
- 只聚合该工作区自身的正式成员及其运行子代理，排除归档、空白、已删除的会话。不按路径前缀混入其他工作区；树形嵌套模式暂不汇总子工作区。
- 工作区标题没有专用扩展槽，因此根据 `[role="treeitem"][data-row-key^="workspace:"][aria-expanded]` 定位工作区行，在原生菜单/新建控件之后追加插件自己的 16px 状态单元。不覆盖行、按钮、折叠状态或宿主样式；若未来宿主调整这些标记，需要适配。
- 订阅会话、工作区和 UI 状态源，无 HTTP 请求或定时轮询。MutationObserver 处理折叠、列表重建及行复用，忽略聊天流式文本更新；重复同步不会添加重复标记。卸载会断开 Observer、退订并删除所有自有标记及样式。
- 提示支持中英文、屏幕阅读器标签和 `prefers-reduced-motion`，不遮挡菜单按钮，点击仍交由工作区行处理。

## 结构与扩展

`client.js` 中的 `installMiddleClick`、`installWorkspaceHeader` 与 `installCollapsedWorkspaceStatus` 分别通过 `ctx.inject` 建立作用域，互不依赖，卸载时各自释放监听与槽注册。后续的小功能继续以独立安装函数扩充，不耦合现有组件。

Host 入口 `index.js` 为空实现，仅承载组合包。`dsh.client.platform: web` 是 Desktop 内嵌界面的客户端目标声明，不会启动额外 WebUI。

## 安装与验证

沿用仓库根目录的安装方式。老版本需在 Desktop 插件管理中卸载后重装；保留包标识不代表宿主支持原地升级。

本地开发可仅安装此包：

```powershell
dsh plugin --profile desktop add --ignore-scripts "link:D:/projects-mine/dsh-plugins/rightbar-middle-close"
```

使用本地源码时，在 Desktop 插件页确认启用，重启 Desktop 后验证。不要同时保留远程副本和另一个包名的重复副本。

```bash
node --test rightbar-middle-close/tests/*.test.mjs
```

自动测试覆盖三个组件的注册/清理、标签手势、按会话解析工作区、自定义名称、路径边界、折叠/展开、运行与完成优先级、等待交互、归档过滤、子代理、DOM 重建及 Observer 幂等性。尚未在 Desktop 实际界面进行视觉及手势验证。

发布需先提交插件源码，再运行根目录说明中的 `index --commit <sha>` 更新远程安装 pin；未提交的新功能只能从本地源码安装。
